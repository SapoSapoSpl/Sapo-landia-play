COMO PUBLICAR NO GITHUB PAGES
1. Crie um repositório público chamado sapolandia-play.
2. Extraia este ZIP.
3. Envie index.html e a pasta assets (não envie o ZIP dentro do repositório).
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Aguarde a publicação.

NOTAS IMPORTANTES
Este pacote é um protótipo front-end de entretenimento. Os jogos têm animação e áudio gerado localmente, mas não são jogos de cassino licenciados nem possuem apostas, prêmio em dinheiro ou saldo sacável. Cadastro e bônus são apenas locais no navegador. Depósito Pix não confirma pagamento nem credita carteira. Saque permanece em manutenção.
Para uma operação real seriam necessários backend seguro, autenticação e armazenamento adequados, provedores de jogos autorizados, pagamentos/saques integrados, prevenção a fraude e cumprimento das normas brasileiras aplicáveis.
